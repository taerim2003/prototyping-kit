# 2026-10-05

## 세션 1 — BlueberryDefense (10/5 밤 ~ 10/6 낮)

**목표**: 테스트 빌드를 뽑아 노션에 올리고, 플레이 중 나온 요청을 그때그때 고친다.

**한 일**: `/build`를 두 번 돌렸다(10/5 DX12 빌드, 10/6 DX11 빌드). 그 사이에 커서 숨김(키보드·패드 선택 시), 독수리 저격 이펙트, 컬렉션 2차 아이콘, 게릴라 콩콩이 착지 순간이동 네 건을 고쳤다. 네 건 모두 컴파일만 통과했고 화면 확인은 못 했다. 추격 화살 렉은 풀링 여부만 답하고 원인은 재지 않았다.

**과정 — 잘 된 것**:
- DX11 여부를 조회 값으로 답하지 않고 빌드 exe를 띄워 `Player.log`로 확정했다. 에디터의 두 조회(`PlayerSettings.GetGraphicsAPIs`와 직렬화 값)가 서로 달랐고, 로그가 한 번에 갈랐다.
- 옆 세션이 메시지로 "고치지 말고 값만 알려 달라"고 한 것이 맞았다. 에디터 값을 건드리지 않고 빌드 결과로 판정했다.
- 콩콩이 건은 "빼 달라"에서 "고칠 수 있으면 고쳐 달라"로 바뀌었는데, 코드 한 줄(착지 시 도약 위상)로 원인이 잡혔다.

**과정 — 막힌 것 / 마찰**:
- Unity MCP가 세션 중 세 번 끊겼다. 그때마다 화면 확인을 포기하고 컴파일 통과로만 넘겼다.
- 오프라인 컴파일 검사(`Tools/compile-check.sh`)가 asmdef 어셈블리(`JuicyUI.Runtime`)의 변경을 못 본다. 이미 빌드된 dll을 참조하기 때문이다. 스크래치패드에 2단 컴파일 스크립트를 따로 짰다.
- 에디터 도메인 리로드가 3분 걸렸고, `ReleaseBuild.Queue()`의 `delayCall`이 두 번 연속 안 돌았다. 첫 번째는 7분을 기다린 뒤에야 알았다.

**AI 협업 체크**:
- 추측으로 진행한 것: "독수리 저격"을 독수리 루트 전체(1차·2차)로 읽었다. 커서 숨김을 레벨업 창만이 아니라 포커스 장치를 쓰는 창 전부에 걸었다. 둘 다 HANDOFF 확인 대기에 적었다.
- 규칙을 어긴 것: 노션 카드를 만들 때 한글을 유니코드 이스케이프로 보냈다(kanban 스킬이 금지한 것). 이번에는 되읽기에서 글자가 전부 맞았지만 세 번째 위반이다.
- 사용자가 지적한 것: "뽑고 있는 거 맞아?"(진행 보고 없이 기다리기만 했다), 빌드 대기 명령을 끊고 옆 세션 메시지를 물었다.
- 잘 결정한 것: 빌드가 `queued`에서 안 넘어갈 때 폴더 시각과 에디터 로그로 "시작 안 됨"을 확인하고 다른 경로로 실행시켰다.

**다음에 바꿀 것**:
- `/build` 스킬에 "`queued`에서 2분 넘게 멈추면 `update` 콜백으로 실행"과 "그래픽 API를 바꾼 첫 빌드는 exe 로그로 확인"을 단계로 넣었다(프로젝트 스킬에 반영 완료).
- `Tools/compile-check.sh`가 asmdef 어셈블리를 먼저 컴파일하도록 고칠 것(아직 안 했다).

**메모**: 노션 「프로토타입 빌드」 페이지에 10/5 zip(DX12)이 남아 있다. 받는 사람이 그걸 받으면 크래시가 재현된다.
