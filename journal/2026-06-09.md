**과정 — 막힌 것 / 마찰**:
- **Windows PowerShell 5.1 한글 인코딩 3중 함정**에 시간 소모: ① `Get-Content`가 UTF-8(no-BOM)을 ANSI로 오독, ② 리다이렉트 시 `[Console]::OutputEncoding` 설정이 예외(exit 255), ③ `.ps1` 자체가 no-BOM이면 스크립트 내 한글 *리터럴*이 깨짐. 테스트 출력의 깨짐이 실제 결함인지 콘솔 렌더링 아티팩트인지 분간하느라 헷갈림.
- 레이아웃 footgun 뒤늦게 발견: wrapper폴더+Unity서브폴더 구조에서 anchored `.gitignore`(`/Library/`)가 중첩 `Library/`를 못 거름.

**다음에 바꿀 것**:
- **한글 PowerShell 스크립트 규칙을 키트에 못박기**: ① `.ps1`은 UTF-8 BOM 저장 ② 파일은 `-Encoding UTF8`로 읽기 ③ stdout은 `OpenStandardOutput()`에 UTF-8 바이트 직접 쓰기. (이번 훅에 이미 적용. 향후 훅/에디터 스크립트 작성 시 기본값으로.)
