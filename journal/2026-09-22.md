## 세션 1 — 블루베리 디펜스 (Steam 업적)

**목표**: "정상 클리어하면 전부 깰 수 있는" 도전과제 계획 → 구현.

**한 일**: 콘텐츠 전수 조사(진입점 배열 기준) → 봇 완주 기록 50회로 기준값 실측 → 업적 26개 설계·코드 배선(`Achievements.cs` 창구 + 훅 한두 줄씩, 세이브 소급 판정). 오프라인 컴파일 통과. 칸반 「Steamworks에 도전과제 등록하기」 카드 생성. **커밋은 보류**(병렬 세션이 같은 파일 작업 중).

**과정 — 잘 된 것**:
- 기준값을 감으로 안 잡고 봇 완주 로그(`runs.jsonl`)를 캠페인 단위로 묶어 쟀다 → "2차 진화는 50회 중 21회가 엔딩까지 안 나온다"가 드러났다. 설계 원칙("저절로 받는다")을 깨는 항목을 구현 전에 잡았다.
- 해금 조건(정수·맵)을 업적 코드에 복사하지 않고 로스터 에셋(`CharacterDefinition.IsUnlocked`)에 직접 물었다 — 사본이 안 생긴다.

**과정 — 막힌 것 / 마찰**:
- 노션 카드 생성에 한글을 유니코드 이스케이프로 보냈다(kanban 스킬이 금지한 것). 되읽기 단계에서 이상 없음을 확인했지만, 규범은 또 안 먹혔고 **되읽기 단계가 유일한 방어선**이라는 게 다시 확인됐다.
- Python이 없는 환경에서 치환 스크립트를 짜서 한 번 날렸다(Edit 툴로 재작업).
- 병렬 세션이 "어머니→군집체" 일괄 치환을 하면서 내가 쓴 HANDOFF 문장까지 바꿔 뜻이 뒤집혔다("주석의 '어머니'는 그대로 둠" → "'군집체'는 그대로 둠"). wrap에서 발견해 고쳤다.
- wrap의 커밋 단계가 병렬 세션과 부딪혔다 — 같은 파일에 남의 미완성 변경이 섞여 있어 커밋 불가.

**AI 협업 체크**:
- 사용자는 "계획을 세워줘"라고 했는데, 계획 승인 뒤 그대로 구현까지 갔다. 결과적으로 사용자가 이어서 요청을 줬지만(엘리트 삭제·군집체 문구), 범위가 한 단계 넓어진 건 맞다.
- 업적 이름·영어 문구 초안은 내가 지었다(Steamworks 입력 전에 사용자가 고칠 것).
- 자율 결정 중 괜찮았던 것: 병렬 세션 busy를 `ListAgents`로 확인하고 커밋을 보류한 것.

**다음에 바꿀 것**: 병렬 세션이 여럿 도는 날엔 wrap 커밋을 "마지막에 끝나는 세션"이 몰아서 하게 된다 — 지금은 HANDOFF에 "커밋 안 됨 + 내 파일 목록"을 남기는 것으로 넘긴다(규칙화는 한 번 더 겪으면).

**메모**: 에디터·봇에선 Steam이 꺼져 `[ACH]` 로그만 찍힌다. 실제 팝업 검증은 Steamworks 등록 뒤 베타 브랜치 빌드로.

## 세션 2 — 블루베리 디펜스 (스킬트리 툴팁 글자 위치)

**목표**: 노드 호버 툴팁의 글자가 판 위로 삐져나오는 것 고치기.

**한 일**: 판 그림(`개큰네모_색칠`) 색·알파를 열별로 스캔해 밝은 면(위 46~200px)을 잼 → `Tooltip`의 Name·Desc·Cost 칸을 그 안으로 옮김 → 가장 긴 이름·설명으로 캡처 확인 → 에디트모드에서 씬 저장. 커밋은 `Title.unity`에서 **내 hunk 3개만** 패치로 스테이징(같은 파일에 병렬 세션의 크레딧 변경이 섞여 있음).

**과정 — 잘 된 것**:
- CLAUDE.md §5-1 "판 실루엣을 PNG로 재서 배치"를 그대로 따랐더니 한 번에 맞았다. 가장 긴 문구로 찍은 게 최악 조건 검증이 됐다.
- 같은 파일에 병렬 세션 변경이 섞여 있어도 `git apply --cached`로 내 hunk만 골라 커밋할 수 있었다 — 세션 1의 "커밋 보류"보다 나은 길. 한 번 더 쓰이면 wrap 스킬에 넣을 것.

**과정 — 막힌 것 / 마찰**:
- 한글 파일명을 PowerShell 스크립트에 넘기느라 한 번 돌았다(스크래치로 복사해 해결). PS 실행 정책도 `-ExecutionPolicy Bypass`가 필요했다.
- 툴팁을 띄웠는데 안 보였다 — 스킬트리 창 자체가 닫혀 있었다(부모 체인 `activeSelf`를 찍고 알았다).

**AI 협업 체크**:
- 사용자가 켜 둔 플레이모드를 내가 껐다(씬 저장 때문). 묻지 않고 진행했고 보고에 적었다.
- 설명 칸이 93→73px로 줄어 3줄 초과 설명은 자동 축소된다 — 현재 최장 2줄이라 괜찮다고 판단.
