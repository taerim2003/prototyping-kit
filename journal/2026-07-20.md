**AI 협업 체크**:

**목표**: Phase 0에서 확정한 로드맵의 Phase 1 완주 — RunConfig + MapDefinition + RunBootstrap + 적스탯·스케일링·XP커브를 SO로 추출. 완료조건 = "기본맵 선택 시 현재와 100% 동일".

**한 일**:

- 에셋 생성/프리팹·씬 배선/검증을 전부 `script-execute`(에디터 C#)로 — GUID 손 안 대고 AssetDatabase가 처리. EnemyDef 7종+Map_BlueberryField+ScalingTable 생성, 7 프리팹 definition 배선, 씬 배선·저장.
- 플레이모드 스모크: 무예외, stage1 시작, 물량스폰 9/14, Blueberry spd2/hp14, XP18 — 완료조건 충족.

**과정 — 잘 된 것**:
- **착수 전 세 갈림길을 AskUserQuestion으로 확정**(RunConfig id타입·EnemyDefinition 이관범위·BGM 스코프). 각각 추천안을 1번 옵션+근거로 제시. 되돌리기 비용 큰 결정을 코드 쓰기 전에 못박음.
- **완전 이관 리스크를 "현재 실효값 먼저 정확히 캡처"로 관리.** grep으로 프리팹 스탯을 뽑다가 대부분 프리팹이 `essenceDropChance` 등을 **직렬화 안 하고 C# 기본값(0.15/2)에 의존**하는 걸 발견 → SO에 그 값을 명시적으로 재현. 이걸 놓쳤으면 드랍률이 조용히 바뀔 뻔.
- **script-execute 파이프라인**: 생성→배선→리플렉션 검증→플레이모드 스모크를 MCP 왕복 안에서 자기완결. 프리팹 private `definition`도 SerializedObject로 안전 배선.
- 계획 맹종 안 함: RunConfig의 `CharacterDefinition` 참조를 Phase 3로 미룸(투기적, §2). ScalingTable을 전역 유지(맵별 아님)로 결합 얕게, 미할당 시 `.Default` 폴백으로 안전.

**과정 — 막힌 것 / 마찰**:
- **🟡 에디트모드 Instantiate는 Awake를 안 돎.** 런타임 필드(definition→복사값)를 리플렉션으로 검증하려다 전부 0 — Awake 미실행 탓. `definition` 참조 자체를 직접 검증하는 방식으로 전환(1왕복 낭비). 결정적 검증은 결국 플레이모드에서.
- 사용자가 내 추천(프리팹 유지)과 다른 **"완전 이관"**을 선택 → 작업량↑. 스코프를 밸런스 스칼라 6개로 한정하고 플래그·VFX·사망분출은 프리팹 잔류로 리스크 낮춤.

**AI 협업 체크**:
- 추측으로 진행? — 안 함. 세 결정 다 물었고, 프리팹 실효값도 추측 대신 grep+Read로 확인(미직렬화 발견이 핵심). 씬 GUID(stageTable·background)도 파일에서 캡처.
- 암묵 전제? — 없음. RunConfig Character 필드 제거, ScalingTable 전역 유지 등 계획 편차를 근거와 함께 고지.
- 자율 결정 잘한 것 — 완전이관 리스크를 "실효값 캡처+스칼라 한정"으로 낮춤, script-execute 배선/검증 자동화, 전역 폴백(`.Default`)로 미할당 NRE 방지. 재현할 것.

**다음에 바꿀 것**:
- **[→ Kit] Unity 에디트모드 Instantiate는 Awake 미실행** — 프리팹 런타임 초기화 검증은 (a)serialized 참조값 직접 확인 or (b)플레이모드에서. 런타임필드를 에디트모드에서 읽어 검증하려 들지 말 것.
- **[→ Kit] SerializeField→SO 이관 시 "프리팹이 그 필드를 직렬화했는지" 먼저 확인.** 미직렬화 필드는 YAML에 없고 C# 기본값이 실효값 — 그 기본값을 SO에 명시 재현해야 밸런스 불변.

**메모**:
- Phase 1 완료. 다음 = Phase 2(맵 선택 화면). 현재 맵 에셋은 Map_BlueberryField 하나 — 2번째 맵을 실제로 만들지는 Phase 2 착수 시 사용자 확인.
- ScalingTable을 맵별로 뺄지(후반 난이도 맵별 차등)는 열린 결정으로 BALANCE_MAP에 기록.

**과정 — 잘 된 것**:
