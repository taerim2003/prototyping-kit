# journal — 세션 일기 (전역)

프로토타입을 가리지 않고 **모든 세션의 일기**가 여기 날짜순으로 쌓인다.
목적은 게임 회고가 아니라 **프로토타이핑 과정 자체의 개선** — "워크플로에서 뭐가 막혔고 다음엔 뭘 바꿀까."

- 파일명: `YYYY-MM-DD.md`
- 하루 여러 세션 → 같은 파일에 `## 세션 N` 블록 추가
- 틀: [../templates/JOURNAL_ENTRY.md](../templates/JOURNAL_ENTRY.md)
- 작성 시점: 세션 종료 루틴 (각 프로토타입 `CLAUDE.md` §9)

주기적으로 일기를 훑어 반복되는 마찰을 찾고, 해결책을 `_KIT`의 템플릿·규칙에 반영해 영구화한다.
