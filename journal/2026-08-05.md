**과정 — 막힌 것 / 마찰**:
1. 🔴 **`script-execute` 결과를 `Debug.Log`로 찍었다가 못 읽었다.** `console-get-logs`는 훅에 막혀 있다 — 스킬에 그렇게 적혀 있는데도 로그로 출력하는 코드를 짰다. 반환값(`return sb.ToString()`)으로 바꿔서 해결. **결과를 어떻게 받을지가 script-execute의 첫 결정인데 그게 절차에 없었다.**
2. 🔴 **Unity가 꺼져 있는 걸 늦게 알았다.** `.meta`가 없는 것을 보고서야 프로세스를 확인했다. `brief` 4단계에 "씬 작업이면 MCP 로드 확인"이 있지만 **첫 턴 후보에 씬 작업이 없어서 안 봤고**, 사용자가 아이콘을 넣으면서 씬 작업이 됐다.
3. **Unity 6 API 변경으로 `script-execute`가 두 번 컴파일 실패했다** — `TextureImporter.spritePixelsToUnit` 없음(→ `TextureImporterSettings` 경유), `FindObjectsSortMode` deprecated.
4. **`AddComponent(Enemy)`가 조용히 null을 반환했다** — `[RequireComponent(typeof(Collider2D))]`인데 `Collider2D`가 추상이라 Unity가 자동 추가를 못 한다. 에러 메시지("Non-static method requires a target")가 원인을 안 가리켜서 한 번 헛돌았다. `BoxCollider2D`를 먼저 붙여 해결.
5. **사용자 아트 파일명을 안 묻고 개명했다**(`Swing.png` → `Icon_Swing.png`). 컨벤션 일치라 판단하고 선언 후 진행했다. 결과는 문제없었지만 사용자 파일이었다.
